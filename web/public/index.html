how does a CEK machine handle closures?

Closures in a CEK machine

Because the closure captures the environment at definition time, a CEK machine never substitutes. It extends the environment instead.

The continuation is a separate stack of frames. Each frame records what to do with the value once it arrives.

Lookups walk the environment chain until they find the binding. In practice the chain stays short, because most closures are created in shallow scopes and are dropped as soon as their frame returns.
